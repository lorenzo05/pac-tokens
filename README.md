# Usage left bar for Claude Code

Shows how much of your Claude usage you have left, the 5-hour and weekly limits, right above the prompt in Claude Code:

```
5-hour: 77% left (resets in 2h 14m)   Weekly: 92% left (resets in 4d 6h)   [Hide]
```

## Install

In Claude Code on your computer:

```
/plugin install token-band --marketplace lorenzo05/pac-tokens
```

In the desktop app: + next to the prompt box → Plugins → Add marketplace → `lorenzo05/pac-tokens` → Add plugin.

Type `/tokens` to show or hide it. It shows in the terminal and in the desktop app's local sessions; cloud sessions and claude.ai chats don't draw plugin bars.
