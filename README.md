# PAC-TOKENS

A Claude Code mod that shows your token usage as a Pac-Man arcade above the prompt: Pac-Man eats the context window, the four ghosts close in as it fills up, and the bottom row shows your rate limits and the session cost as fruit.

## Install

```
/plugin install token-band --marketplace lorenzo05/pac-tokens
```

In the desktop app: + next to the prompt box → Plugins → Add marketplace → `lorenzo05/pac-tokens` → Add plugin.

Type `/tokens` to show or hide it.
