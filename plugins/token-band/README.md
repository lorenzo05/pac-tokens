# token-band

A Pac-Man game that plays itself right above the prompt in Claude Code, in the arcade's own colours: Pac-Man laps the maze eating dots, Blinky, Pinky, Inky and Clyde come at him, a power pellet turns them blue so he can hunt them, and a ghost that catches him costs a life. Under the maze it shows how much of your usage you have left, the 5-hour and weekly limits, coloured green, then orange under 40%, then red under 15%, with when each resets. Press Hide or run /tokens to toggle it. It draws in the terminal and the desktop app on your own computer.
